# Comment for IntelliJ

This is an IntelliJ implementation of [Kary Coding Standards](https://github.com/pouyakary/coding-standards) comments, or Kary Comments, ascii-based markers to bring consistent and clear layout to code.

All credit goes to [Pouya Kary](https://github.com/pouyakary) for his initial idea. Please check out his official implementation for Visual Studio Code.
